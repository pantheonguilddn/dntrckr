Guild administration

Pantheon Admin Console

Manage approved Discord accounts, character registrations and Main designations, and the one-time JSONBin migration. Do not share the old JSONBin master key; it is used only for the one-time import form and is not saved by this page.

1. Add an approved Discord account

Use the account's numeric Discord user ID, not a username. The member does not need to configure cloud sync after being allowlisted.

Pantheon normally matches a Discord profile name to the same-named Member Roster owner automatically. Use Roster match name only if those names differ; enter the exact owner name once. To copy a Discord ID, enable User Settings → Advanced → Developer Mode, then right-click the user's profile and choose Copy User ID.

2. Tool launcher

The sidebar has been removed from member accounts. Launch tools from here when working as an administrator. Each link opens Pantheon in a separate tab, where the app checks the signed-in role again. Global changes to dungeon tasks, loot weights, and version savepoints are restricted to administrators.

3. Character registration & Main designation

Admin-only controls for every member’s registered IGNs, class / job, tracking opt-in, and Main designation. Changing a registration requires that member to confirm their details again at their next login.

4. Move the old guild record from JSONBin to D1

Run this once, from an administrator session, to copy the existing tracker and revision journal into Cloudflare D1. The target records are the private IDs used by the new Pantheon backend. This leaves the old JSONBin records untouched as a backup.

5. Initialize an empty database instead

Use this only if there is no JSONBin data to migrate. It creates a clean, empty tracker record. It will not overwrite an existing main record.
